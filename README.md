## 📖 Sobre o projeto

O **Habit Tracker** é uma aplicação web estática criada para facilitar o acompanhamento de hábitos e ajudar o usuário a manter uma rotina mais consistente.

A aplicação permite cadastrar hábitos personalizados, definir categorias e cores, registrar diariamente se cada hábito foi concluído e acompanhar o desempenho através de métricas e calendários.

O projeto possui uma interface focada em produtividade, com navegação por abas, sidebar recolhível e diferentes visualizações para acompanhar a evolução dos hábitos.
